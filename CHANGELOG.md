# CHANGELOG

## 0.4.2
- Исходники приведены к читаемому виду: настоящие лямбды вместо синтетических
  методов, комментарии, понятные имена переменных.
- Поведение не изменилось.

## 0.4.1
- Убрано тёмное кольцо вокруг красного бейджа — теперь просто красный круг с цифрой.

## 0.4.0
- На значке показывается **число** уведомлений, а не просто точка.
- Правильная русская форма числа («1 новое уведомление», «3 новых уведомления»).
- Подпись под значком: `Название · N`.
- `setContentDescription` для доступности.

## 0.3.0
- Тестовая «проверка значка» (точка горит 10 секунд).
- Обходной путь для закрепления виджета на vivo через `JumpOriginWidgetActivity`.

## 0.2.0
- Подсчёт активных уведомлений через `NotificationListenerService`.
- Исключение служебных уведомлений (`FLAG_SKIP`, `FLAG_AUTOMATIC`).

## 0.1.0
- Первый выпуск: значок-точка вместо числа уведомлений.
